# Contributing to Study Jam DevOps Community

Terima kasih telah berkontribusi! Ikuti panduan berikut agar profil anggota konsisten dan mudah ditinjau.

## 1. Aturan Kontribusi

- Tambahkan **satu file Markdown baru** untuk profilmu di folder `participants/`.
- Jangan mengubah atau menghapus file profil peserta lain.
- Jangan mengubah `README.md` atau `CONTRIBUTING.md` untuk kontribusi profil biasa.
- Gunakan bahasa yang sopan dan isi yang sesuai untuk komunitas belajar.
- Pastikan tidak ada informasi pribadi sensitif.

## 2. Aturan Nama File

Gunakan nama lengkap atau nama panggilan yang ingin dipublikasikan, dengan huruf kecil dan tanda hubung sebagai pemisah kata.

Contoh:

```text
participants/ari-pratama.md
participants/siti-nur-hidayah.md
```

Hindari spasi, huruf kapital, dan nama file generik seperti `profile.md` atau `biodata.md`. Jika nama file yang ingin digunakan sudah ada, pilih nama yang lebih spesifik agar tidak menimpa profil lain.

## 3. Template Profil

Salin template berikut ke file profilmu dan isi bagian yang relevan:

```markdown
## Halo, kenalan yuk!

Hai, aku **[nama lengkap]**. Senang bisa jadi bagian dari Study Jam DevOps!

- **Kelas:**
- **Program studi (prodi):**
- **Asal:**
- **Tahun mengikuti Study Jam:**
- **Motivasi mengikuti Study Jam DevOps:**
- **Hal yang ingin dipelajari:**
- **Fun fact (opsional):**
```

Isi secara ringkas. Untuk bagian asal, cukup gunakan informasi umum yang nyaman kamu bagikan, misalnya kota atau daerah. Fun fact bersifat opsional.

## 4. Workflow Kontribusi

1. Fork repository ini ke akun GitHub kamu.
2. Clone repository hasil fork ke komputer lokal.
3. Buat branch khusus, misalnya `feat/tambah-profil-ari-pratama`.
4. Tambahkan file profil di folder `participants/`.
5. Periksa perubahan sebelum commit.
6. Buat commit dengan pesan yang deskriptif, misalnya `feat: tambah profil Ari Pratama`.
7. Push branch ke repository hasil fork.
8. Buat Pull Request ke branch utama repository sumber.
9. Periksa kembali repository tujuan dan deskripsi PR sebelum mengirim.
10. Tanggapi masukan reviewer dan lakukan revisi jika diperlukan.

## 5. Checklist Sebelum Membuat Pull Request

- [x] File profil berada di folder `participants/`.
- [x] Nama file mengikuti aturan penamaan.
- [x] Isi profil menggunakan template yang tersedia.
- [x] Saya hanya menambahkan atau mengubah file yang menjadi tanggung jawab saya.
- [x] Tidak ada informasi sensitif yang dipublikasikan.
- [x] Commit message menjelaskan perubahan.
- [x] Pull Request ditujukan ke repository sumber Study Jam DevOps, bukan hanya ke fork saya sendiri.

## 6. Review dan Merge

Pengelola atau reviewer dapat meminta perubahan jika format tidak sesuai, nama file membingungkan, atau konten perlu diperbaiki. Pull Request akan digabungkan setelah memenuhi panduan kontribusi.

Kontribusi yang diterima menjadi bagian dari buku komunitas Study Jam DevOps.
